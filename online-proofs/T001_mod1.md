S1. For each initial condition \(x(0)=x_0\in\mathbb R^n\), the linear system \(\dot x=Ax\) has the global solution \(x(t)=e^{At}x_0\) for all \(t\ge 0\).

S2. Define \(V:\mathbb R^n\to\mathbb R\) by
\[
V(x)=x^T P x.
\]
Since \(P=P^T>0\), there exist constants \(\lambda_{\min}(P)>0\) and \(\lambda_{\max}(P)>0\) such that for all \(x\in\mathbb R^n\),
\[
\lambda_{\min}(P)\|x\|^2\le V(x)\le \lambda_{\max}(P)\|x\|^2.
\]

S3. Along any solution \(x(t)\),
\[
\dot V(x(t))
=\dot x(t)^T P x(t)+x(t)^T P\dot x(t)
=x(t)^T A^T P x(t)+x(t)^T P A x(t)
=x(t)^T(A^T P+P A)x(t).
\]

S4. Let
\[
Q=-(A^T P+P A).
\]
By hypothesis \(A^T P+P A<0\), so \(Q=Q^T>0\). Hence there exists \(\lambda_{\min}(Q)>0\) such that
\[
x^T Q x\ge \lambda_{\min}(Q)\|x\|^2
\]
for all \(x\in\mathbb R^n\).

S5. Therefore
\[
\dot V(x(t))
=-x(t)^T Q x(t)
\le -\lambda_{\min}(Q)\|x(t)\|^2.
\]

S6. From S2,
\[
\|x(t)\|^2\ge \frac{V(x(t))}{\lambda_{\max}(P)}.
\]
Thus
\[
\dot V(x(t))
\le -\frac{\lambda_{\min}(Q)}{\lambda_{\max}(P)}V(x(t)).
\]
Set
\[
c=\frac{\lambda_{\min}(Q)}{\lambda_{\max}(P)}>0.
\]
Then
\[
\dot V(x(t))\le -cV(x(t)).
\]

S7. Integrating this differential inequality gives
\[
V(x(t))\le e^{-ct}V(x(0))
\]
for all \(t\ge 0\).

S8. Using S2 again,
\[
\lambda_{\min}(P)\|x(t)\|^2
\le V(x(t))
\le e^{-ct}V(x(0))
\le e^{-ct}\lambda_{\max}(P)\|x(0)\|^2.
\]
Hence
\[
\|x(t)\|
\le \sqrt{\frac{\lambda_{\max}(P)}{\lambda_{\min}(P)}}e^{-ct/2}\|x(0)\|.
\]

S9. To prove Lyapunov stability, let \(\varepsilon>0\). Choose
\[
\delta=\varepsilon\sqrt{\frac{\lambda_{\min}(P)}{\lambda_{\max}(P)}}>0.
\]
If \(\|x(0)\|<\delta\), then by S8,
\[
\|x(t)\|
\le \sqrt{\frac{\lambda_{\max}(P)}{\lambda_{\min}(P)}}e^{-ct/2}\|x(0)\|
<
\sqrt{\frac{\lambda_{\max}(P)}{\lambda_{\min}(P)}}\delta
=\varepsilon.
\]
Thus for every \(t\ge 0\), \(\|x(t)\|<\varepsilon\). Therefore the origin is Lyapunov stable.

S10. To prove convergence, take any \(x(0)\in\mathbb R^n\). From S8,
\[
\|x(t)\|
\le \sqrt{\frac{\lambda_{\max}(P)}{\lambda_{\min}(P)}}e^{-ct/2}\|x(0)\|.
\]
Since \(c>0\), \(e^{-ct/2}\to 0\) as \(t\to\infty\). Hence \(\|x(t)\|\to 0\). The case \(x(0)=0\) is trivial.

S11. Since the origin is Lyapunov stable and every solution converges to the origin as \(t\to\infty\), the origin is globally asymptotically stable.

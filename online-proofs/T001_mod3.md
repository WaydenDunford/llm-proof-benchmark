S1. Define the candidate Lyapunov function $V(x)=x^TPx$.

S2S1. Define the candidate Lyapunov function as $V(x) = x^T P x$.

S2. Because $P$ is symmetric positive definite, its eigenvalues are real and strictly positive. Let $\lambda_{\min}(P)$ and $\lambda_{\max}(P)$ denote the smallest and largest eigenvalues of $P$, yielding the spectral bounds $\lambda_{\min}(P) \Vert{}x\Vert{}^2 \le V(x) \le \lambda_{\max}(P) \Vert{}x\Vert{}^2$ for all $x \in \mathbb{R}^n$.

S3. Because the system $\dot{x} = Ax$ is a linear ordinary differential equation with a constant matrix $A$, a unique solution $x(t)$ exists globally for all $t \ge 0$ for any given initial condition $x(0) = x_0 \in \mathbb{R}^n$.

S4. Differentiate $V(x)$ with respect to time along a solution trajectory to obtain $\dot{V}(x) = \dot{x}^T P x + x^T P \dot{x}$.

S5. Substitute the system dynamics $\dot{x} = Ax$ into the derivative to get $\dot{V}(x) = (Ax)^T P x + x^T P (Ax) = x^T A^T P x + x^T P A x = x^T (A^T P + P A) x$.

S6. Define the symmetric matrix $Q = -(A^T P + P A)$. The assumption $A^T P + P A < 0$ implies $Q$ is positive definite, meaning its eigenvalues are strictly positive. Thus, we have the spectral bound $\dot{V}(x) = -x^T Q x \le -\lambda_{\min}(Q) \Vert{}x\Vert{}^2$, where $\lambda_{\min}(Q) > 0$.

S7. Rearrange the upper bound from S2 to obtain $\Vert{}x\Vert{}^2 \ge \frac{V(x)}{\lambda_{\max}(P)}$, and substitute this into S6 to derive the scalar differential inequality $\dot{V}(x(t)) \le -\frac{\lambda_{\min}(Q)}{\lambda_{\max}(P)} V(x(t))$.

S8. Define the constant $\alpha = \frac{\lambda_{\min}(Q)}{\lambda_{\max}(P)} > 0$. Integrating the scalar differential inequality $\dot{V}(t) \le -\alpha V(t)$ over time yields $V(x(t)) \le V(x_0) e^{-\alpha t}$ for all $t \ge 0$.

S9. Combine S2 and S8 to write $\lambda_{\min}(P) \Vert{}x(t)\Vert{}^2 \le V(x(t)) \le V(x_0) \le \lambda_{\max}(P) \Vert{}x_0\Vert{}^2$, which simplifies to $\Vert{}x(t)\Vert{} \le \sqrt{\frac{\lambda_{\max}(P)}{\lambda_{\min}(P)}} \Vert{}x_0\Vert{}$. For any $\epsilon > 0$, choosing $\delta = \epsilon \sqrt{\frac{\lambda_{\min}(P)}{\lambda_{\max}(P)}}$ guarantees that if $\Vert{}x_0\Vert{} < \delta$, then $\Vert{}x(t)\Vert{} < \epsilon$ for all $t \ge 0$, which formally establishes Lyapunov stability of the origin.

S10. Utilize the integrated inequality from S8 to establish that $0 \le \lambda_{\min}(P) \Vert{}x(t)\Vert{}^2 \le V(x_0) e^{-\alpha t}$. Because $\alpha > 0$, $\lim_{t \to \infty} V(x_0) e^{-\alpha t} = 0$. By the squeeze theorem, this requires $\lim_{t \to \infty} \Vert{}x(t)\Vert{} = 0$ for every initial condition $x_0 \in \mathbb{R}^n$, formally establishing global convergence to the origin.

S11. Conclude that because the origin is both Lyapunov stable and guarantees convergence to the origin for every initial state in $\mathbb{R}^n$, it is globally asymptotically stable.

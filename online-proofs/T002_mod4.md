S1. Suppose (x_n) is a sequence in the metric space (X, d) with x_n → a and x_n → b, where a, b ∈ X.

S2. By the definition of convergence, x_n → a means: for every ε > 0, there exists N₁ ∈ ℕ such that for all n ≥ N₁, d(x_n, a) < ε.

S3. By the definition of convergence, x_n → b means: for every ε > 0, there exists N₂ ∈ ℕ such that for all n ≥ N₂, d(x_n, b) < ε.

S4. Let ε > 0 be arbitrary. Applying S2 with ε/2 in place of ε, there exists N₁ such that for all n ≥ N₁, d(x_n, a) < ε/2.

S5. Applying S3 with ε/2 in place of ε, there exists N₂ such that for all n ≥ N₂, d(x_n, b) < ε/2.

S6. Let N = max(N₁, N₂). Since N ≥ N₁ and N ≥ N₂, both bounds hold simultaneously at index N: d(x_N, a) < ε/2 and d(x_N, b) < ε/2.

S7. Since d is a metric, it satisfies the triangle inequality: for any three points of X, in particular d(a, b) ≤ d(a, x_N) + d(x_N, b).

S8. Since d is a metric, it is symmetric, so d(a, x_N) = d(x_N, a). Substituting into S7 gives d(a, b) ≤ d(x_N, a) + d(x_N, b).

S9. Combining S6 and S8: d(a, b) ≤ d(x_N, a) + d(x_N, b) < ε/2 + ε/2 = ε.

S10. Thus d(a, b) < ε. Since ε > 0 was arbitrary, this inequality holds for every ε > 0.

S11. Since d is a metric, d(a, b) ≥ 0 (non-negativity is part of being a metric). If d(a, b) were strictly greater than 0, then choosing ε = d(a, b) in S10 would yield d(a, b) < d(a, b), a contradiction.

S12. Therefore no such positive value is possible, so d(a, b) = 0.

S13. By definiteness of the metric, d(a, b) = 0 if and only if a = b. Since d(a, b) = 0 by S12, it follows that a = b.

S14. Hence, if a sequence (x_n) in a metric space converges to both a and b, then a = b, proving that limits in a metric space are unique. ∎

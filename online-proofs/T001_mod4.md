S1. **Definitions.** A point x* is an *equilibrium* of ẋ = Ax if Ax* = 0. The origin is *Lyapunov stable* if for every ε > 0 there exists δ > 0 such that, for every solution x(t) with |x(0)| < δ, |x(t)| < ε for all t ≥ 0. The origin is *globally asymptotically stable (GAS)* if it is Lyapunov stable and, in addition, every solution satisfies x(t) → 0 as t → ∞ regardless of x(0) (global attractivity). Since A·0 = 0, the origin is an equilibrium of ẋ = Ax.

S2. **Global existence.** For any x₀ ∈ ℝⁿ, the linear ODE ẋ = Ax, x(0) = x₀, has the unique solution x(t) = e^{At}x₀, defined for all t ∈ ℝ, and in particular for all t ≥ 0. Thus every solution is defined on the full interval [0, ∞), so questions of stability and convergence may be posed for all t ≥ 0.

S3. **Bounds on V from P.** Define V(x) = xᵀPx. Since P = Pᵀ > 0, all eigenvalues of P are real and positive; let 0 < λ_min(P) ≤ λ_max(P) denote the smallest and largest. By the spectral (Rayleigh quotient) bounds for quadratic forms of real symmetric matrices,
λ_min(P)|x|² ≤ V(x) ≤ λ_max(P)|x|² for all x ∈ ℝⁿ.
Hence V(0) = 0, V(x) > 0 for x ≠ 0, and V(x) → ∞ as |x| → ∞.

S4. **Q is symmetric positive definite.** Let Q := −(AᵀP + PA). Using Pᵀ = P,
(AᵀP + PA)ᵀ = PᵀA + AᵀPᵀ = PA + AᵀP = AᵀP + PA,
so AᵀP + PA is symmetric, and hence so is Q. By hypothesis AᵀP + PA < 0, so Q = −(AᵀP+PA) > 0. By the spectral bound for symmetric positive definite matrices, letting λ_min(Q) > 0 be its smallest eigenvalue,
xᵀQx ≥ λ_min(Q)|x|² for all x ∈ ℝⁿ.

S5. **Derivative of V along solutions.** Let x(t) solve ẋ = Ax. Differentiating V(x(t)) = x(t)ᵀPx(t) using ẋ = Ax,
d/dt V(x(t)) = ẋᵀPx + xᵀPẋ = (Ax)ᵀPx + xᵀP(Ax) = xᵀAᵀPx + xᵀPAx = xᵀ(AᵀP + PA)x = −xᵀQx,
where the argument t of x(t) is suppressed for brevity.

S6. **Differential inequality for V.** Combining S5 with the lower bound on Q (S4) and the upper bound on P (S3),
d/dt V(x(t)) = −x(t)ᵀQx(t) ≤ −λ_min(Q)|x(t)|² ≤ −(λ_min(Q)/λ_max(P)) V(x(t)).
Set α := λ_min(Q)/λ_max(P) > 0 (positive since both λ_min(Q) and λ_max(P) are positive). Then
d/dt V(x(t)) ≤ −α V(x(t)) for all t ≥ 0.

S7. **Integration of the scalar differential inequality.** Consider φ(t) := V(x(t)) e^{αt}. Then
φ'(t) = e^{αt}(V̇(x(t)) + αV(x(t))) ≤ 0
by S6, so φ is nonincreasing on [0, ∞); hence φ(t) ≤ φ(0) = V(x₀) for all t ≥ 0. Dividing by e^{αt} > 0 gives
V(x(t)) ≤ V(x₀) e^{−αt} for all t ≥ 0,
for every initial condition x₀ ∈ ℝⁿ (this holds regardless of the size of x₀, since S2–S6 impose no restriction on x₀).

S8. **Norm bound.** Applying the lower spectral bound on P and the upper spectral bound on P (S3) to both sides of S7,
λ_min(P)|x(t)|² ≤ V(x(t)) ≤ V(x₀) e^{−αt} ≤ λ_max(P)|x₀|² e^{−αt}.
Dividing by λ_min(P) > 0 and taking square roots,
|x(t)| ≤ κ |x₀| e^{−αt/2} for all t ≥ 0, where κ := √(λ_max(P)/λ_min(P)) ≥ 1.
This estimate holds for every x₀ ∈ ℝⁿ.

S9. **Lyapunov stability.** Let ε > 0 be given, and choose δ := ε/κ > 0. If |x₀| < δ, then by S8, for all t ≥ 0,
|x(t)| ≤ κ|x₀| e^{−αt/2} ≤ κ|x₀| < κδ = ε,
using e^{−αt/2} ≤ 1 for t ≥ 0. Thus |x(0)| < δ implies |x(t)| < ε for all t ≥ 0, which is exactly the definition of Lyapunov stability of the origin (S1).

S10. **Global attractivity.** Fix any x₀ ∈ ℝⁿ (no smallness restriction) and let x(t) be the corresponding solution. By S8,
0 ≤ |x(t)| ≤ κ|x₀| e^{−αt/2}.
Since α > 0, e^{−αt/2} → 0 as t → ∞, so the right-hand side tends to 0. By the squeeze principle, |x(t)| → 0, i.e., x(t) → 0 as t → ∞. As x₀ was arbitrary, every solution converges to the origin regardless of initial condition.

S11. **Conclusion.** By S9, the origin is Lyapunov stable; by S10, every solution converges to the origin from any initial condition. By the definition of global asymptotic stability (S1), these two properties together establish that the origin is globally asymptotically stable for ẋ = Ax. ∎
